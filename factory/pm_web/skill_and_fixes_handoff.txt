File B: /home/taza/repo/tools/code-consistency-check/scripts/audit_refs.py
A pure-stdlib, single-file AST checker with these semantics:
  - Parse the file; collect signatures of every top-level function and class,
    and of every @dataclass class (its annotated fields = its required params).
  - Walk every Call. For a plain-name call to a locally-defined target, verify:
      * no keyword arg is a name the target doesn't have  -> bad-keyword
      * positional count <= target's max positional       -> too-many-positional
      * every required param is satisfied by position or keyword
                                                          -> missing-required
    For a call to an undefined name (not builtin, not imported, not a param,
    not private) emit undefined-call.
  - Walk each class for self.attr reads never assigned in that class
    (skip dataclass/annotated fields, self-methods, __class__/__dict__) -> self-attr-missing.
  - Output: "path: N finding(s)" + one line per finding; exit 0 clean, exit 1
    findings. The list MUST not crash on any file containing classes/dataclasses.

Note for a fresh instance: do NOT hand-write from memory and hope for an exact
hash — just build a correct, self-tested checker (the functional test below
defines correctness).
